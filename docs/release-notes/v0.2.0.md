### What's new in 0.2.0

- **Proxy support.** Use an HTTP or SOCKS5 proxy, or the one from your system settings, with an optional username and password (stored encrypted). It works for downloads, video downloads, tool installs and the update check. **Settings → Proxy**, with a *Test connection* button.
- **"What's new" window.** After an update, KDM tells you what changed. You can open it again from **Settings → About**.
- **"Last try" column.** The compact list shows the date and time of each download's last attempt.
- **A cleaner list.** The lines between downloads and the column header row are gone, and the sidebar is a little narrower with a smaller menu font, so the list gets more room.
- **Browser extension:** the *Download video* button now shows the real KDM logo.
