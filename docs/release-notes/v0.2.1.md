### What's new in 0.2.1

- **Fixed: the browser's "Download video" button downloaded the wrong video.** On a page with several videos (a feed, a gallery, a list of previews) the button could send another video from the page. It now works out which video you clicked (its own file, the link to its page, or the stream it started loading) and downloads that one. **Reload the KDM extension** in `chrome://extensions` to get this fix.
- **A "Download complete" window.** When a download finishes, the progress window closes and a separate window opens on top of all other windows, with the file name, where it was saved, its size and speed, and **Open** / **Open folder** buttons. It can be turned off in the window itself or in Settings. Files the queue downloads in the background only show a notification.
- **Fixed: update check failed with "GitHub responded 403".** GitHub limits how often one internet address may ask for updates, so shared networks and VPNs could be refused. KDM now falls back to GitHub's release pages. **This fix is inside the app, so install 0.2.1 by hand once** (the buttons on the project page); after that, automatic updates work again.
