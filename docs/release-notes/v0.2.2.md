### What's new in 0.2.2

- **Fixed: the "Update Available!" button did nothing.** GitHub renamed the project's repository (the name now has capital letters), and the app wrongly refused the new download address. The button now downloads and installs the update again, and shows the reason if something goes wrong instead of staying silent. **Because the bug was inside the app, install 0.2.2 by hand once** (the buttons on the project page); after that, automatic updates work again.
- **Update found too early.** If KDM looked for updates while a new release was still being built, the button sent you to the web page. KDM now waits until the installer is attached and checks again by itself.
- Includes everything from 0.2.1: the right video from the browser button on pages with several videos, the "Download complete" window, and the fix for "GitHub responded 403" on shared networks and VPNs.
